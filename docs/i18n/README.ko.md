# Gen1Recomp 포켓몬 언어 모드

**Uni-Language Ascendant** · Pokémon Red / Blue / Yellow / Gold / Silver / Crystal / FireRed / LeafGreen / Ruby / Sapphire / Emerald.

Uni-Language Ascendant는 한국어 금·은 게임 언어를 지원합니다. 언어 ROM을 가져온 뒤 ASCENDANT → UNI-LANGUAGE에서 전환합니다. 메뉴 언어와 게임 언어의 지원 범위는 다릅니다.

[Download / GitHub Releases](https://github.com/Roxas2712/uni-language-ascendant/releases/latest) · [English guide & screenshots](https://roxas2712.github.io/uni-language-ascendant/) · [Supported profiles](https://roxas2712.github.io/uni-language-ascendant/#languages)

10 menu languages; 41 localized game profiles. Consult the edition matrix and exact ROM SHA-1 requirements.
