Install a Gen1Recomp language mod

  1. Import the exact supported English US base game in Gen1Recomp.
  2. Download the mod ZIP from GitHub Releases, install it through the mod manager and enable Uni-Language Ascendant.
  3. Import your matching language ROM through the launcher’s mod imports or the desktop file picker in the in-game language menu. On platforms without a host file picker, use the launcher’s Imports panel. Compare the complete file’s SHA-1 with the ROM version checklist.
  4. Choose the menu language and the available game language. The Ascendant intro runs once per mod profile.

Sapphire PT-BR uses the exact Ruby PT-BR import with separate Sapphire recipes and authored compatibility text. FRLG PT-BR patch-source revisions differ from the runtime US base: follow the checksum list.

ASCENDANT → UNI-LANGUAGE

Choose a game language, change the menu language immediately, add a language ROM or check the required revision and SHA-1. Unavailable game languages remain visible and disabled.

A game-language change uses an in-process session handoff. At a settled overworld location, the current progress is kept in memory, enabled mods reload with the new language, and play resumes at the same location. The application stays open during the loading pause. Large Ascendant combinations take noticeably longer than the language mod alone. The first compilation takes longer than using a cached language.

Dialogue, battle, movement, transitions and online rooms must finish first. The normal save file is not overwritten by the switch. A failed switch attempts to restore the previous language; an interrupted handoff retains a separate recovery record.

KASC and VASC share an Ascendant menu descriptor; the fallback hub can collect their entries alongside Languages. Origami Gen3 receives a language entry in its Ascendant menu. See the release QA for the exact tested combinations.

Questions about ROMs, translations and compatibility

Which games are supported?

Pokémon Red, Blue, Yellow, Gold, Silver, Crystal, FireRed, LeafGreen, Ruby, Sapphire and Emerald, when supported by the underlying recompiler. Check the language matrix for each edition.

Which ROM do I need?

Use the supported English US base game and the exact language ROM listed in the ROM checklist. Version, revision and SHA-1 must match. The ZIP contains mod code and recipes; users supply their own ROM inputs.

Does the European Emerald ROM contain all languages?

No. Supported Emerald language editions are separate ROM inputs. USA/Europe identifies a region and does not supply a multilingual language selector.

How does live language switching work?

At a settled overworld location, open ASCENDANT → UNI-LANGUAGE. The mod keeps unsaved progress in memory, reloads the current game session in the same application, and resumes at the current location. A first-time compilation can take longer than switching a cached language.

Can I switch during dialogue, battle or an online session?

Finish the active dialogue, battle, movement or transition first. Switching is intended for settled offline overworld play. The menu refuses unsafe states.

Can I use Kanto Ascendant or Voxel Ascendant?

The language entry uses the shared Ascendant menu descriptor. KASC can collect it into its hub; a fallback hub combines VASC and language entries when KASC is absent. Compatibility results for tested versions are published with the release. Arbitrary mod combinations are not universally certified.

Are all ten menu languages also available in every game?

No. English, German, French, Italian, Spanish, Japanese, Korean, Simplified Chinese, Traditional Chinese and Brazilian Portuguese are menu options. Actual game profiles are listed in the matrix.

What happens when I update or uninstall?

Updates preserve the imported ROMs and mod profile. Uninstalling deletes the mod profile; reinstalling starts a new profile. A language switch does not overwrite the normal game save.
