Required ROM revisions & SHA-1

Gen1Recomp requires the matching English US base. Each language profile additionally requires the exact source below. The checksum identifies the complete, uncompressed ROM file; a matching file name is insufficient. The mod checks both the size and MD5 import receipt, plus SHA-1 in the in-game importer.

PT-BR inputs are fan translations, not official releases. See patch projects and source revisions. Sapphire PT-BR uses the listed Ruby translation source, with a separate Sapphire profile. This project does not distribute source ROMs.
